# Julia's Personal Wesbite

Hi! This is the repo hosting my personal website, using ![Bioinformatics.ca's Jupyter Book template](https://cbw-dev.github.io/jupyterbook-template/intro.html), which was developed using Jupyter Book.

> Note that many old unused files are still present, those are simply so I have reminders of markdown formatting and capabilities.

## Dev Reminders
- Build locally in `PersonalWesbite` with `jupyter-book build --all .`
- Deploy using `ghp-import -n -p -f _build/html`
