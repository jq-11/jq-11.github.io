5 POC Websites

Under bioinformatics.ca, I created 5 POC websites to test different static website generators to find a new format for the Canadian Bioinformatics Workshops (CBW). Either Proof-of-Concept (POC) pages or recreations of the CBW Workshop, Introduction to R 2024 (INR 2024) were created to test these static website generators.

  • Bookdown
  • Carpentries
  • Jupyter Book
  • Docusaurus
  • Quarto
    • Templates and Documentation

    These are templates are made for future workshop creators to be able to easily make a workshop website without any previous website development experience.

    These are the corresponding documentation for the websites, to help explain to new users how to use the templates.
